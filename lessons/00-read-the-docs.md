# Lesson 0: read the docs with your AI

Your first task is to check an AI explanation against a source, then practice reviewing requests safely. Allow 25 to 30 minutes. Use the desktop workspace from [Start here](../START-HERE.md), or read this lesson in a browser with an ordinary chat if that is the access you have.

Use your existing AI allowance. This lesson installs nothing and needs no app-hosting account.

## Ask for the source

Documentation explains how a tool works and how to use it. For products, start with the maker's documentation. For web basics, this course uses MDN, a maintained reference. The formal HTML standard is published by [WHATWG](https://html.spec.whatwg.org/multipage/sections.html#headings-and-outlines).

Ask your tutor:

```text
Open MDN's heading reference:
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements
Explain what <h1> means using the introduction and one small example.
Show the source link and separate its facts from your advice.
Then ask me to explain it back. Do not edit files.
```

If the tool cannot open the page, open it yourself and paste the short relevant excerpt. The tutor should state which source it could actually inspect.

## Check the explanation

Open [MDN's heading reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/Heading_Elements) yourself. Check the publisher in the address bar, then read the introduction and example.

Explain `<h1>` in one sentence. It represents the highest level of heading and describes document structure. Its appearance can be changed separately.

Compare your answer and the AI's explanation with the page. If the AI disagrees with the source, quote the relevant line and ask it to correct its explanation. You only need the section that answers your question.

## Check whether instructions apply

Ask the tutor what you should check before following a setup guide. Look for the operating system, supported software version, and service plan. Open release notes when a guide and your tool disagree. A publication date alone does not establish that an instruction is right or wrong.

Our [tool and cost checks](../docs/tools-and-costs.md) record dated source reviews. Reopen the official sources before a later installation or purchase.

## Work safely before editing

Complete [Work safely with AI](../docs/ai-safety.md) now, then return here. It provides the permission check and read-only exercises. Later lessons introduce security checks alongside the tool they concern.

## Try it yourself

Ask your AI where the text in an HTML `<title>` appears. Request the source and check the answer against [MDN's title reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/title).

You have completed this lesson when you can identify the source, explain a heading versus a browser-tab title, and complete the safety checkpoint in your own words. Record which permission controls you actually inspected; ordinary chat does not establish a desktop check.
