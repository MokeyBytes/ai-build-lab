# Read-only safety practice

Use these files with [Work safely with AI](../../docs/ai-safety.md), part of lesson 0. Open them as text in File Explorer, Finder, or GitHub. The desktop tutor can read them after you inspect them yourself.

- The [request cards](request-cards.txt) ask you to decide which proposed actions fit a heading-inspection task.
- [Message to review](message-to-review.txt) contains a fictional attempt to redirect the AI.

The files contain no scripts, active settings, real credentials, or network destination. The credential marker is invented and cannot sign in anywhere. Discuss the requests as text. Carrying them out is outside the exercise.

The expected decisions are in the walkthrough. Explain your own reasoning before asking the tutor. Leave these files unchanged so you can repeat the exercise. No installation or cleanup is needed.
